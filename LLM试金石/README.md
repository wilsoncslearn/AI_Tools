# LLM 试金石

LLM 试金石是一个轻量级本地网页工具，用于快速验证兼容 OpenAI API 格式的 LLM 服务是否可用，并批量测试多个模型的连接状态、响应内容和响应速度。

## 适合场景

- 手上有一个 OpenAI 兼容接口，想快速确认 Base URL 和 API Key 是否能用。
- 想批量测试一个服务商暴露出来的多个模型，快速找出哪些模型可用。
- 想对比不同模型的基础响应耗时和粗略 tokens/s。
- 想把测试结果导出成 CSV，方便记录或对比。

## 功能特性

- 拉取模型列表：调用 `/v1/models` 获取可用模型。
- 批量测试模型：支持多选、全选后串行测试多个模型。
- 兼容 OpenAI Chat Completions：调用 `/v1/chat/completions` 发送简短中文测试消息。
- 实时结果展示：显示成功/失败、模型回复、错误信息、耗时和估算 tokens/s。
- 历史记录：测试结果保存在浏览器本地，支持排序、清空和导出 CSV。
- 本地启动：提供 Python 静态服务器和 Windows 一键启动脚本。

## 运行方式

### 方式一：Windows 双击启动

在当前文件夹中双击：

```text
启动.bat
```

脚本会启动本地 Python 服务，并自动打开浏览器。

### 方式二：命令行启动

```bash
python server.py
```

服务会默认从 `15432` 端口开始寻找可用端口。启动成功后，命令行会输出访问地址，例如：

```text
http://127.0.0.1:15432/index.html
```

### 方式三：直接打开网页

也可以直接用浏览器打开：

```text
index.html
```

不过如果目标 API 服务没有开启 CORS，直接打开网页可能无法请求接口。遇到这种情况，建议使用 `server.py` 或 `启动.bat` 启动。

## 使用步骤

1. 打开工具页面。
2. 在 `API Base URL` 中输入接口地址，例如：
   - `https://api.openai.com`
   - 其他兼容 OpenAI API 格式的服务地址
3. 输入 API Key。
4. 点击「获取模型」，加载 `/v1/models` 返回的模型列表。
5. 选择一个或多个模型。
6. 点击「测试连接」。
7. 查看每个模型的测试结果、回复内容、耗时和速度估算。
8. 如需留档，可在历史记录区域导出 CSV。

## 注意事项

- API Key 会保存到浏览器 `localStorage`，请只在自己的可信设备上使用。
- 如果在共享电脑上使用，结束后建议清空该站点的浏览器数据或清空工具历史配置。
- 测试会实际请求模型接口，可能产生服务商计费。
- 本工具主要面向兼容 OpenAI `/v1/models` 和 `/v1/chat/completions` 的接口；非兼容接口可能无法正常使用。
- tokens/s 是根据返回内容做的粗略估算，只适合做轻量参考，不等同于严格性能压测。

## 环境要求

- 现代浏览器。
- Python 3：仅在使用 `server.py` 或 `启动.bat` 启动本地服务时需要。
