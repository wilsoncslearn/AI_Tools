# LLM 试金石

LLM 试金石是一个轻量级本地网页工具，用于快速验证兼容 OpenAI API 格式的 LLM 服务是否可用，并批量测试模型连接状态与响应速度。

## 功能特性

- 输入 API Base URL 与 API Key，拉取 `/v1/models` 模型列表。
- 支持按供应商分组展示模型，并可多选/全选进行批量测试。
- 通过 `/v1/chat/completions` 发送短消息验证模型可用性。
- 实时展示每个模型的测试结果、耗时、估算 tokens/s 与错误信息。
- 在浏览器本地保存测试历史，支持排序、清空与导出 CSV。
- 提供本地 Python 静态服务器与 Windows 一键启动脚本。

## 运行方式

### 方式一：双击启动（Windows）

进入 `LLM试金石` 文件夹，双击 `启动.bat`。脚本会启动本地服务并自动打开浏览器。

### 方式二：命令行启动

```bash
cd LLM试金石
python server.py
```

启动后访问命令行中输出的地址，默认从 `http://127.0.0.1:15432/index.html` 开始寻找可用端口。

### 方式三：直接打开网页

也可以直接用浏览器打开 `LLM试金石/index.html`。如果目标 API 服务未开启 CORS，建议使用上面的本地服务器方式。

## 使用说明

1. 在「API Base URL」中输入接口地址，例如 `https://api.openai.com` 或其他兼容 OpenAI API 的服务地址。
2. 输入 API Key。
3. 点击「获取模型」加载可用模型。
4. 选择一个或多个模型。
5. 点击「测试连接」开始串行测试。
6. 在结果区查看成功/失败、响应内容、耗时与速度估算。
7. 可在历史记录区域导出 CSV 或清空记录。

## 注意事项

- API Key 会保存到浏览器 `localStorage`，请只在可信设备上使用；共享电脑使用后请清空浏览器站点数据或历史配置。
- 测试请求会实际调用模型接口，可能产生服务商计费。
- 本工具面向兼容 OpenAI `/v1/models` 与 `/v1/chat/completions` 的接口；非兼容接口可能无法正常测试。

## 环境要求

- 现代浏览器。
- Python 3（仅在使用 `server.py` 或 `启动.bat` 时需要）。
